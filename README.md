# 神将降魔 · 修仙放置（玩法框架）

一个手机端 **PWA 修仙放置游戏**的玩法框架，玩法参考手游《神将降魔》。
纯前端、零构建、无依赖，直接托管在 GitHub Pages，手机浏览器打开后「添加到主屏幕」即可像原生 App 一样全屏离线运行。

## 已实现的玩法框架

- **境界修炼**：凡人 → 炼气 → 筑基 → 结丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫，每个大境界分 初期/中期/后期/巅峰 四小境界；突破靠灵气（气海阈值），突破时属性按倍率翻涨。
- **属性体系**：生命 / 攻击 / 防御 / 气海 / 神识 / 力量 / 速度 / 寿元 / 天道，以及综合战力。
- **流派与灵根**：灵修·剑修·体修三流派 + 金木水火土五行灵根（创建角色时选择）。
- **副本战斗**：回合制自动战斗（带暴击、速度连击），通关推进、掉落材料/装备/丹药。
- **神将阁**：招募神将、消耗灵石+灵草升阶，神将属性并入角色。
- **背包与装备**：材料 / 丹药（使用）/ 装备（穿戴），三槽位。
- **轮回**：元婴起可转世重修，获得轮回点（永久 +10% 全属性）。
- **天道**：现实每秒 +2 小时天道（占位，后续接入功法领悟）。
- **离线收益**：离线最多累计 8 小时灵气与灵石。
- **存档**：本地 localStorage 自动保存，Service Worker 支持完全离线。

## 目录结构

```
index.html          入口与脚本加载顺序
manifest.webmanifest PWA 清单
sw.js               Service Worker（离线缓存）
css/style.css       样式（深色修仙风）
data/*.js           内容数据（改内容只动这里）
js/util.js          工具函数
js/data.js          数据访问层
js/store.js         状态/存档/属性计算
js/systems.js       玩法系统（突破/战斗/神将/轮回/离线）
js/ui.js            界面渲染与路由
js/app.js           启动/主循环/事件
```

## 怎么改内容

所有玩法内容都是 **data/\*.js** 里的纯数据数组，改完 push 一次即生效：

- `realms.js` 境界（名称、气海阈值、属性、倍率、寿元）
- `paths.js` 流派与灵根
- `heroes.js` 神将
- `stages.js` 副本/BOSS/掉落
- `items.js` 材料/丹药/装备

## 本地运行

任意静态服务器均可（如 `python3 -m http.server 8000`），浏览器打开即可。离线缓存与 PWA 安装需通过 http(s) 访问。

## 部署

推送到 GitHub 仓库并启用 Pages（`Settings → Pages → main 分支`）。
